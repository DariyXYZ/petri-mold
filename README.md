# Чашка Петри

Мини-игра-арт-объект: чёрно-белая пиксельная чашка Петри, в которой растёт плесень.

**→ [Играть](https://dariyxyz.github.io/petri-mold/)**

Ставишь кликами до 8 спор внутри чашки, жмёшь пробел — колонии прорастают вразнобой,
конкурируют за питание, упираются друг в друга и наслаиваются. Через минуту-полторы
культура созревает и останавливается. Каждый прогон неповторим, но воспроизводим:
seed лежит в адресной строке.

## Управление

| | |
|---|---|
| клик внутри чашки | поставить спору (повторный клик по ней — убрать) |
| пробел | запустить рост |
| `A` | та же культура заново |
| `R` | новая чашка |
| `S` | сохранить PNG |
| `D` | панель настроек |

## Как это устроено

Ванильный HTML + Canvas 2D. Ни сборки, ни зависимостей — `index.html` открывается
двойным кликом с диска.

Симуляция идёт в буфере 380×389 (пропорция исходной фотографии), который выводится
на экран целочисленным масштабом с отключённым сглаживанием. Яркость квантуется в
8 уровней серого с упорядоченным дизерингом Bayer 4×4 — отсюда пиксельная фактура.

### Рост

Гибрид клеточного фронта и агентов-кончиков. Морфология колонии — не отдельный
алгоритм на каждый вид, а одна score-функция с разными весами:

```
S = wN·N + wD·D + wP·P + wR·R + wDrift·A − wC·C − wI·I − wB·B + η
```

где `N` — питательность клетки, `D` — лопастная анизотропия, `P` — поддержка своими
соседями, `R` — кольцевой ритм, `A` — снос роста в одну сторону, `C` — теснота от
чужих, `I` — ингибитор, `B` — штраф у стенки, `η` — связный шум. Дальше сигмоида
превращает `S` в вероятность занять клетку.

Ключевое поле — **ингибитор**: колонии выделяют его при заселении, он слабо
диффундирует и подавляет рост. На контакте двух колоний он удваивается, фронты
встают, и между ними сам собой появляется тёмный зазор или тонкий белый шов.

Десять архетипов: бархат, пузыри, гифы, лопасти, кольца, розетка, дендрит, плёнка,
облако, призрак. Два последних живут в отдельном полупрозрачном слое поверх
остальных — он и даёт наложения.

Разброс размеров берётся из трёх источников: степенное распределение лимита клеток,
разное время прорастания спор и неоднородное поле питания.

## Структура

```
index.html
css/style.css
js/rng.js       детерминированный ГСЧ (mulberry32) и fBm-шум
js/palette.js   палитры и LUT квантования
js/dish.js      геометрия и графика чашки
js/fields.js    поля симуляции
js/growth.js    архетипы, score-функция, агенты-кончики
js/scene.js     композитинг биомассы и полупрозрачного слоя
js/render.js    дизеринг, квантование, апскейл
js/ui.js        панель и горячие клавиши
js/main.js      игровой цикл и состояния
```

## Референс

Геометрия чашки, палитра и композиция сняты замерами с фотографии чашки Петри:
центр, четыре полосы обода, сетка миллиметровки под стеклом, подсветка снизу.
